# Tic-Tac-Toe game

Tic-Tac-Toe is a simple two-player strategy game played on a 3×3 grid.

Players take turns placing their symbol—typically X or O—in an empty cell. The objective is to be the first to align three of your symbols horizontally, vertically, or diagonally.

If all nine cells are filled without either player achieving this, the game ends in a draw.

It’s commonly used as a basic example in programming and game development because of its straightforward rules but still requires simple strategic thinking.
